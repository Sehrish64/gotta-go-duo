# Demo GIF plan (15 to 20 seconds)

A good demo GIF at the top of the README is the single biggest thing for stars. Everything below is free.

## Tools (free)
- **Windows:** ScreenToGif (records straight to GIF) or OBS Studio + ezgif.com to convert
- **Phone or Mac:** built-in screen recorder, then convert the video at ezgif.com
- Keep the GIF **under 10 MB**, about **800 px wide**, **10 to 12 fps**. Longer than 20s is too heavy.

## Setup before recording
1. Use a test server and a second account (or a friend) as the duo partner.
2. Both join the same voice channel so the sound effects play (GIFs have no sound, but the "Voice chat ON" line looks great on screen).
3. Use dark mode, hide your real name and other servers, zoom the Discord window to 110%.

## Shot list
| Time | What is on screen |
|---|---|
| 0-2s | Type `/gotago friend:@buddy` and hit enter |
| 2-4s | Buddy taps **Let's go!**, both pick characters (Captain Quack vs Mango Mike) |
| 4-8s | Turn embed with hurdle + panic meter + "🗣️ Discussion time" countdown |
| 8-11s | Buttons unlock, press a move (the "🔒 Locked in" message pops up) |
| 11-15s | The reveal: both moves, hurdle result, meter jumps |
| 15-20s | Ending card: "🚽 YOU MADE IT!" with the friendship score |

## Tips
- Cut the waiting: set `discussion` to 20 seconds, or edit the GIF to skip the timer.
- Add the GIF as `assets/demo.gif`, then in README.md uncomment the demo line under the banner.
- Also make a still screenshot of the ending card and the `/gotago_leaderboard` embed for the README.
- Post the GIF on social media too, with the repo link. Short, funny clips travel well.
